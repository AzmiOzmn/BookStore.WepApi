# Kitap Kiralama Sistemi BookStore

**Kitap Kiralama Sistemi *BookStore* , API ve kullanıcı arayüzü katmanlarından oluşan modern bir web uygulamasıdır. API katmanı kitap yönetimi, kiralama ve abonelik işlemlerini sağlarken, UI katmanı kullanıcı ve admin paneli olarak API’yi tüketir.

---

## Proje Katmanları

- Entity Layer  
- Data Access Layer  
- Business Layer  
- API Katmanı  
- UI Katmanı 

---

## Özellikler

- Kitapların listeleme, ekleme, güncelleme ve silme işlemleri  
- Kullanıcı abonelik işlemi (AJAX ile) 
- Admin paneli üzerinden kitap ve kullanıcı yönetimi  
- Swagger ile API dokümantasyonu  

---

## Kullanılan Teknolojiler

- ASP.NET Core Web API
- ASP.NET MVC
- Entity Framework Core (DB First)  
- AJAX (abonelik işlemleri için)  
- Swagger
- AutoMapper
